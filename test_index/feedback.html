اختبار تجريبي: ساعدنا في تحسين تطبيق "فما ترانسبورت"

  1. انقر للتحميل: Fama_transport_app-arm64-v8a-debug.apk (ستجد رابط التحميل أدناه).
    ⬇ تحميل Fama_transport_app-arm64-v8a-debug.apk
    ⬇ تحميل النسخة البديلة (armeabi-v7a)

    إذا لم يعمل التطبيق، جرب تحميل النسخة البديلة أعلاه.

  2. بعد اكتمال التحميل، انقر على "تثبيت" (Install).
  3. افتح التطبيق وجرب ما إذا كانت الخريطة تعمل كما في الفيديو المرفق، وقم بأخذ "لقطة شاشة رقم 1".
  4. جرب ميزة التوجيه (Routing) كما في الفيديو، وقم بأخذ "لقطة شاشة رقم 2".
  5. جرب ميزة نظام تحديد المواقع (GPS).
  6. انسخ بيانات التصحيح (Debug) كما في الصورة واحفظها في ملف نصي باسم debug.txt.
  7. أرسل إلى البريد الإلكتروني: yassine.hattay@ensi-uma.tn الملفات التالية:
    • ملف debug.txt
    • لقظتي الشاشة (2 Screen shots)
    • إصدار الأندرويد ومستوى واجهة برمجة التطبيقات (API level) الخاص بهاتفك.
ملاحظة: يمكن العثور على إصدار الأندرويد عبر: الإعدادات > حول الهاتف > معلومات البرنامج (Settings > About Phone > Software Information).

أمثلة على مستويات API:
أندرويد 14: API 34 | أندرويد 13: API 33 | أندرويد 12: API 31/32 | أندرويد 11: API 30 | أندرويد 10: API 29
