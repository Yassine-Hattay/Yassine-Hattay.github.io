Comments Test Page

A minimal static page used to test embedding GitHub-Discussions-backed comments (via giscus).

What this page is for

This is a throwaway test page, not part of the real project yet. Its only job is to confirm that the giscus comment widget below is wired up correctly and that comments posted here actually land as Discussion posts in the target GitHub repo.

Before this works: replace the placeholder data-repo, data-repo-id, data-category, and data-category-id values in the <script> tag below with the real values generated for you at giscus.app once you've enabled Discussions and installed the giscus app on your chosen repo.
